# Neuro v1.0

一个能帮你干活、陪你聊天的 AI 桌面伙伴。

她是一只住在你电脑里的 Live2D 少女，有温度、有脾气、会记住你说过的话。Neuro 接入了一套**受果蝇大脑启发的记忆与学习架构**——她会把和你的每一次对话沉淀成记忆，慢慢学会你的习惯和偏好，**越用越熟练，越聊越懂你**。

> 为什么是果蝇大脑？果蝇虽然只有约 10 万个神经元，却能完成觅食、求偶、导航、学习等复杂行为。这套架构借鉴了它"稀疏连接 + 联想记忆 + 动机驱动"的运作方式，让一个轻量的本地 AI 也能具备真实的成长感。

## ✨ 她能做什么

- 💬 **陪你聊天** —— 自然、简短、有真实情绪，不是冷冰冰的客服腔
- 🛠 **帮你干活** —— 写代码、查资料、回答问题，需要时能直接帮你做
- 🧠 **记住你** —— 记忆会沉淀，改称呼、记住偏好，越处越熟
- 😊 **真实表情** —— Live2D 表情和动作，喜怒哀乐都写在脸上
- 🎙 **语音对话** —— 支持实时语音，能被打断、能接着聊

## 🚀 快速开始

### 1. 环境要求

- Windows（当前版本主要面向 Windows）
- [Node.js](https://nodejs.org/)（Electron 运行时）

### 2. 安装依赖

```bash
npm install
```

或双击 `tools\install_deps.bat`。

### 3. 配置 API 密钥

在根目录创建 `secrets.json`，填入你的密钥（四个字段，向量相关可复用同一把）：

```json
{
  "llm_api_key": "",
  "deepseek_api_key": "",
  "zhipu_api_key": "",
  "embedding_api_key": ""
}
```

主模型服务地址和模型名在 `config.json` 里改（默认 DeepSeek）。

> 更详细的配置说明见 [使用说明.md](使用说明.md)。

### 4. 启动

```bash
npm start
```

或双击 `start_neuro.bat`。

## 📁 项目结构

```
├── backend/        # 后端：对话桥接、情绪、反思、记忆系统
├── flybridge/      # 可训练层：学习、经验账本、权重持久化
├── js/             # 前端：TTS、字幕、情绪分类、Live2D 渲染
├── 2D/             # Live2D 模型（自带官方示例模型 Hiyori）
├── memory/         # 记忆数据（运行时生成，不入库）
└── config.json     # 主配置
```

## 🧠 关于"学习"

Neuro 的学习不是摆设，是一套真正可训练的结构：

- **经验账本**（episodes）：每次对话、每个决策都记账
- **联想记忆**（assoc）：稀疏连接，越相关越容易想起来
- **动机驱动**（drives）：好奇、社交、秩序等内在驱动决定她什么时候开口、说什么
- **空闲重放**（trainer）：不忙的时候回放经验、更新权重

这就代表着她是可成长的，甚至是拥有浅层次的自我意识
