# Neuro 使用指南

从零到跑起来，再到改配置、看架构、跑测试。**如果你只想启动，看第 2、3 节就够了。**

---

## 1. 你需要什么

| 项 | 要求 |
|---|---|
| 系统 | Windows 10/11（Electron 透明置顶窗口 + Live2D） |
| Python | 3.10+（要能 `python -m pip`） |
| Node.js | 18+（Electron 28 依赖） |
| 磁盘 | 约 600MB（Electron + 依赖 ~300MB，脑数据 260MB） |
| 网络 | 首次要能访问 GitHub（下脑数据）与你的 LLM 接口 |

---

## 2. 安装

```bat
:: 一键装依赖（npm install + pip install -r backend\requirements.txt）
tools\install_deps.bat
```

装完后确认两个东西都在：

```bat
node_modules\electron\dist\electron.exe      :: 没有它 start_neuro.bat 会直接退出
python -c "import fastapi, numpy, flybrain"  :: 缺哪个补哪个
```

> `flybrain` 是独立的脑包，`backend\requirements.txt` 里有它。pip 装不上时先 `pip install -U pip`。

---

## 3. 配密钥（只做一次）

```bat
copy docs\config\secrets.json.example secrets.json
```

用记事本打开根目录的 `secrets.json`，填 `llm_api_key`（DeepSeek 或任意 OpenAI 兼容接口）。
密钥也可以直接写进 `config.json` 的 `llm.api_key`，但 `secrets.json` 不进 git，更安全。

---

## 4. 启动

```bat
start_neuro.bat
```

- 它会把自己最小化，然后拉起 Electron；控制台日志在 `logs\electron_console.log`。
- 第一次启动会**自动下载果蝇脑数据约 260MB** 到 `~/fly-data`，进度在脑桥窗口里，之后不再下载。
- 看到桌宠出现、并且日志里出现 `[bridge] http://127.0.0.1:6007 brain=166700 neurons` 就算起来了。

---

## 5. 关闭（不要直接杀进程）

```bat
tools\exit_and_save.bat
```

它写一个 `.quit_request` 标记：Neuro 会说一句道别 → 落盘记忆 → 自己退出，进程树一起收。
30 秒内没关掉再手动关窗口。直接结束进程会丢这一轮的记忆。

---

## 6. 常见错误

| 现象 | 原因 | 处理 |
|---|---|---|
| `Electron is not installed yet` | `node_modules` 没装 | 跑 `tools\install_deps.bat` |
| 脑桥起不来 / `Bad CRC-32 for file 'indices.npy'` | `~/fly-data` 里的下载是残缺的 | **删掉整个 `~/fly-data` 再启动**，会重新下 |
| 日志里 `[brain] 已清理残留分片 N 个` | 之前用别的下载器留下 `*.p00…p15` 分片 | 程序已自动清掉，无需处理 |
| 端口 6006 / 6007 被占用 | 上次没退干净，留了孤儿进程 | `taskkill /F /T /IM electron.exe`，或重启 |
| 有文字但完全没声音 | `edge-tts` 版本太低（<7.3，微软直接 403） | `pip install -U "edge-tts>=7.3"` |
| 能打字，但说话它听不见 | 语音模型没放 | 见 `backend/models/sensevoice/README.md`（模型 228MB，不随仓库发布） |
| 401 / 402 / 余额不足 | 密钥错或额度用完 | 换 `secrets.json` 里的 key |
| 窗口透明但空白 | GPU 合成问题 | 已默认 `--disable-gpu`；仍不行删 `logs` 后重启 |

## 7. 只改这几个配置就够了

全部在根目录 `config.json`。改完要**重启**才生效（`start_neuro.bat`）。
密钥建议放 `secrets.json`（见第 3 节），`config.json` 里留空。

| # | 键 | 默认值 | 改它会怎样 |
|---|---|---|---|
| 1 | `llm.upstream_url` | `https://api.deepseek.com/v1` | 换模型厂商就改这里。任何 OpenAI 兼容的 `/v1` 都行 |
| 2 | `llm.model` | `deepseek-flash` | 模型名。换成更强的模型她话会更聪明，但更慢更贵 |
| 3 | `llm.api_key` | 空（读 `secrets.json`） | 密钥。填错就是 401；余额不足是 402 |
| 4 | `language.reply` | `en` | 她说哪种语言：`en` / `zh`。**改这个比改提示词管用** |
| 5 | `tts.en_voice` | `en-US-AvaMultilingualNeural` | 她的音色。多语言音色才能中英混说 |
| 6 | `tts.pitch` / `tts.rate` | `+42Hz` / `-15%` | 音高与语速。`+42Hz` 是偏高的少女音，嫌尖就调到 `+20Hz` |
| 7 | `mind.utility.threshold` | `0.27` | **她多容易被触发**。调高=更安静，调低=更爱插话 |
| 8 | `flybridge.hz` | `30` | 脑的步进频率。`50`≈生物实时（更吃 CPU），`30` 是 0.6 倍速 |

顺便知道这几个开关：

| 键 | 默认 | 作用 |
|---|---|---|
| `asr.online.enable` | `true` | 语音识别总开关。设 `false` 就只听键盘 |
| `vision.enabled` | `true` | 屏幕视觉。关掉省电，但她看不见你在干嘛 |
| `idle.speak_after_s` | `45` | 安静多久她会自己开口 |
| `memory.retrieval_threshold` | `0.45` | 记忆召回门槛。调高=只提最相关的，调低=更容易翻旧账 |
| `ui.show_chat_monitor` | `false` | 调试用：显示对话监控窗 |

不要动的：

- `api_key` / `secrets.json` 之外任何带 `sk-` 的值，都不要提交到 git。
- `flybridge.data_dir` 留空即可：空=用 `~/fly-data`，填死路径会让别人跑不起来。
- `mind.ablation.*`：消融实验开关，日常全 `false`，打开会真的关掉对应模块。

## 8. 一页架构

一句话：**脑负责"状态与许可"，程序负责"感官、语言、执行"。**

脑不会想说哪句话——它只回答"现在有多想起来、想靠近还是想缩、紧不紧张"。说不说、说什么，由程序那边的效用打分 + 语言模型决定。

```
① 脑（flybridge，127.0.0.1:6007，30Hz）
   果蝇全脑连接组 → LIF 神经元群 → 每帧一组连续量
   actions: speak / look / withdraw
   axes:    valence 愉悦 · arousal 唤醒 · tension 紧张 · satiety 满足
   emotion: 无监督聚出来的"情绪簇"
   └─ 不产生语言，只产生状态

② 程序（backend 6006 + Electron）
   感官 → 认知 → 语言 → 执行
```

数据怎么流：

```
麦克风 ──VAD/ASR──┐
屏幕帧 ──视觉模型──┤→ cognition.py 工作记忆 ─┬→ arbiter.py 打分决定"该不该开口"
点击/抚摸 ─────────┘                        │      （脑的 speak/axes 是权重之一）
                                            ↓
                                      LLM 生成回复（流式）
                                            ↓
                              TTS(edge-tts) + 字幕 + Live2D 动作/表情
                                            ↓
                                      memory/ 落盘（情景→语义→程序）
```

- **感官**：`backend/stream_asr.py`（语音）、`js/vision-pump.js`（屏幕）、`js/main.js`（窗口与输入）。
- **语言**：`backend/neuro_server.py`（LLM 上游 + 提示词组装）、`js/tts-processor.js`（流式 TTS）、`js/voice-chat.js`（对话主链）。
- **执行**：`js/command-router.js`（开关应用、音量、文件等本机操作）、`js/model-interaction.js`（动作/表情）。
- **仲裁**：`backend/arbiter.py` 是唯一出口。所有来源（回复 / 视觉 / 空闲主动）都走它的 `decide()`，它可以判"沉默"。
- **记忆**：`memory/` 下的 JSON/JSONL；离线巩固在 `backend/consolidation.py`。

端口与进程：

| 端口 | 谁 | 说明 |
|---|---|---|
| 6006 | Python 后端（FastAPI） | LLM / TTS / ASR / 记忆 / 仲裁 |
| 6007 | 脑桥（`python -m flybridge.brain_server`） | 连接组脑，被后端每 200ms 轮询 |
| 9222 | Electron 调试端口 | 只在测试 `-Live` 时用 |

Electron 主进程负责拉起后两个；`--managed` 让脑桥在桌面端消失后自己退出，避免孤儿进程。

## 9. 测试怎么跑

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests\run_all.ps1
```

看到最后一行 **`ALL GREEN`** 就是全过。覆盖：

1. `backend/` 全部 Python 语法（`compileall`）
2. `config.json` 没有 UTF-8 BOM（有 BOM 后端会静默用默认配置）
3. `js/*.js` 的 `node --check`
4. `tests/` 下的全部 `check_*.js` / `check_*.py` 单测

前置条件：

| 条件 | 说明 |
|---|---|
| `python` 在 PATH 里 | 脚本直接调 `python`。不在 PATH 会看到一排 `FAILED (exit 9009)` |
| `node` 或 `node\` 目录 | 有 `node\node.exe` 就用它，否则用 PATH 里的 `node` |
| 装了 `backend\requirements.txt` | 缺 `numpy`/`fastapi` 的单测会 import 失败 |
| `~/fly-data` 有脑数据 | 涉及脑的单测会去读；没有就先启动一次让它自动下 |

PATH 不对时先这样（在项目根目录执行）：

```powershell
$env:Path = "$PWD\python\Scripts;$PWD\node;" + $env:Path
```

需要应用跑着的（可选）：

```powershell
# 先 start_neuro.bat，再：
powershell -NoProfile -ExecutionPolicy Bypass -File tests\run_all.ps1 -Live
```

`-Live` 只多两步：通过 CDP（9222）确认渲染进程活着、请求 `127.0.0.1:6006/v1/stream-health`。

单个测试：

```powershell
node tests\check_echo_suppression.js
python tests\check_arbiter.py
```

退出码 0 = 过。测试里既有"跑真实函数"的，也有"读源码做结构断言"的——后者用正则匹配代码结构，如果你大改结构，记得同步改断言。

## 10. 目录速查

| 位置 | 作用 |
|---|---|
| `start_neuro.bat` | 启动入口（唯一需要双击的文件） |
| `config.json` | 全局配置 |
| `index.html` | 渲染进程页面 |
| `js/` | 前端全部逻辑（含 `js/app.js`、`js/main.js`） |
| `backend/` | Python FastAPI 后端（6006） |
| `flybridge/` | 果蝇脑桥（6007） |
| `docs/` | 指南与架构文档 |
| `tools/` | 辅助脚本（装依赖 / 退出 / 看日志） |
| `tests/` | 自检测试 |
| `2D/` `fonts/` `vendor/` | Live2D 模型、字体、第三方前端库 |

根目录刻意只保留 6 个文件（`index.html`、`package.json`、`config.json`、`README.md`、`LICENSE`、`start_neuro.bat`），其余都归了目录。

> 想用 git 管理这个目录：把 `docs/gitignore.template` 复制成根目录的 `.gitignore` 再 `git init`，否则 `node_modules/`、`python/`、`memory/`、`secrets.json` 都会被提交。
